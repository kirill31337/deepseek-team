# DeepSeek Team 0.8.2

Уровни рассуждений воркеров теперь соответствуют отдельным режимам DeepSeek: `low`, `high` и `max`. Раньше и `medium`, и `high` выбирали уровень `high` у провайдера, а `max` был недоступен.

- Политика по умолчанию остаётся `auto`: координатор выбирает `low` для ограниченной или механической работы, `high` для обычных задач и `max` для сложной отладки, рассуждений по нескольким файлам или требовательного независимого ревью.
- Если при `auto` конкретный уровень не выбран, воркер использует `high`.
- Старые настройки и команды с `medium` продолжают работать: это совместимый синоним `high`.
- Настройки, среды запуска воркеров, карточки маршрутизации и генерируемые инструкции координатора используют единую шкалу. Документация на русском и английском объясняет новое поведение.

Модель воркеров остаётся `deepseek-flash` с включённым режимом размышлений. Права доступа и обязательная песочница Linux не меняются.

После обновления выполните `deepseek-team init --coordinator codex .` (либо `claude` / `both`) в подключённых проектах, чтобы обновить генерируемые инструкции. Пользовательский текст и сохранённые настройки сохраняются.
