# DeepSeek Team 0.10.1

## English

0.10.1 is the first published 0.10-series release. It ships overhead contract v1
and cuts repeated work. The Linux OS sandbox remains mandatory, and implementation
retries remain explicit.

- Contract v1 ships with the package. Full/linked `setup`/`init` and hook
  refreshes preserve the human guide `docs/agents/delegation.md`, bytes and modes
  outside the block, line endings, and saved policy/config. Installation alone
  grants no attachment or hook trust.
- Re-registering an identical normalized plan is an exact no-op, preserving ids,
  routing, phase, outcomes and timestamps. One-package boundaries, blocking/event
  waits and nonduplicative diff review remain agent recommendations, not
  enforcement.
- Check reuse is opt-in: `checks_reusable` defaults to `false` with explicit
  attestation. `workspace verify --reuse-checks` reuses only valid evidence with
  unchanged represented inputs and environment. Force, changed/unknown inputs and
  failed, altered, truncated or unsafe evidence rerun; readiness, security and
  containment probes stay fresh.
- A bounded private record blocks repeated preparation after well-identified
  pre-provider environment failures while relevant conditions remain confirmed
  unchanged. Changed conditions or
  `--recheck-environment` allow a fresh diagnostic; sandbox, access, admission and
  recovery gates remain intact.
- Worker-slot waits use kernel notifications with fallback, preserving FIFO,
  deadlines and cancellation. Avoiding frequent polling remains an agent
  instruction.
- Explicit `correction_of` links reviewed successful `needs-rework` work to its
  original open workspace and job, starting a new attempt with recorded-ID
  resolution instead of `--workspace`. Compaction hook context restores lineage.
  Invalid, stale, foreign or finalized links fail closed; the omitted-link
  overlap guard is task-local, so cross-task semantic corrections need an
  explicit link.
- Planned state uses schema 2; older formats are diagnosed, not migrated, unlike
  the preserved guide and policy.
- CI check-reuse fixtures now use a private interpreter copy with controlled
  ownership and mode, restoring portable positive tests while keeping the
  production executable-identity guard and mandatory Linux sandbox.

Upgrade, then refresh setup for each coordinator:

```bash
pipx upgrade deepseek-team
deepseek-team setup --runtime codex --no-key   # or claude / both
```

Validation covers `PYTHONPATH=src python3 -m unittest discover -s tests -v` and
installation checks with pip, pipx and uv.

## Русский

0.10.1 — первый опубликованный выпуск серии 0.10. Он приносит контракт накладных
расходов v1 и сокращает повторную координацию. Песочница Linux остаётся
обязательной; автоматических повторов реализации нет.

- Контракт v1 входит в пакет. Полный/связанный `setup`/`init` и hooks сохраняют
  руководство `docs/agents/delegation.md`, байты и режимы вне блока, окончания
  строк и политику. Установка не подключает проект и не даёт доверие hooks.
- Повторная регистрация идентичного плана — точный no-op с сохранением id,
  маршрутизации, фазы, результатов и времени. Границы пакета, блокирующее
  ожидание/ожидание событий и недублирующее ревью diff остаются рекомендациями,
  не гарантиями.
- Reuse включается явно: `checks_reusable` по умолчанию `false` с явным
  подтверждением. `workspace verify --reuse-checks` использует только валидные
  свидетельства при неизменных представленных входах и среде. Force, изменённые/неизвестные
  входы и неуспешные, изменённые, усечённые или небезопасные свидетельства
  требуют запуска; проверки готовности, безопасности и изоляции всегда свежие.
- Приватная запись блокирует повторную подготовку после опознанных сбоев среды
  до обращения к провайдеру при подтверждённо неизменных существенных условиях. Изменённые условия или `--recheck-environment` разрешают
  свежую диагностику; песочница, доступ, допуск и восстановление не обходятся.
- Ожидание слота worker использует уведомления ядра, сохраняя FIFO,
  сроки и отмену. Отказ от частого опроса — инструкция агенту.
- Явный `correction_of` связывает проверенный `needs-rework` с исходными
  незакрытыми workspace и job и начинает новую попытку с разрешением записанных
  id без `--workspace`. Контекст hooks после компакции восстанавливает
  происхождение. Неверные, устаревшие, чужие или финализированные связи
  отклоняются безопасно; защита от пропущенной связи действует в пределах задачи,
  поэтому межзадачным смысловым доработкам нужна явная связь.
- Плановое состояние использует schema 2; старые форматы диагностируются, но не
  мигрируются, в отличие от сохранённых руководства и политики.
- CI-фикстуры reuse применяют приватную копию интерпретатора с контролируемыми
  владельцем и режимом, возвращая переносимость положительных тестов без
  изменения production-защиты исполняемого файла и песочницы Linux. Автоповтора
  нет.
