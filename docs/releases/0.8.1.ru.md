# DeepSeek Team 0.8.1

[English](https://github.com/kirill31337/deepseek-team/blob/main/docs/releases/0.8.1.md) | **Русский**

Пакет в PyPI переименован в **`deepseek-team`**. Название теперь совпадает с командой запуска и подходит для обоих поддерживаемых координаторов: Codex и Claude Code.

- Для установки используйте `pipx install deepseek-team`, `uv tool install deepseek-team` или `python -m pip install deepseek-team` внутри виртуального окружения.
- README на английском и русском описывают установку, обновление и удаление через PyPI. Баннер, переключатель языка и лицензия MIT сохранены.
- В итоговом отчёте координатор отдельно указывает собственную работу, принятые результаты DeepSeek и работу встроенных субагентов, включая доработки и сбои. Приблизительное соотношение вклада участников всегда сопровождается пометкой «субъективная оценка, не измерение» и не выдаётся за измеренную экономию.
- Метаданные, проверки установки и ссылки на PyPI обновлены под новое название пакета. Проверенные файлы выпуска можно публиковать через Twine с токеном PyPI. Для публикации через GitHub Trusted Publishing владелец должен отдельно настроить этот способ.

Если у вас установлен прежний пакет `codex-deepseek-team`, сначала удалите его тем же менеджером пакетов, а затем установите `deepseek-team`. Настройки проектов и сохранённые ключи при удалении Python-пакета останутся на месте. Для перехода на новое название выполнять `auth remove` не нужно.

Для работы нужны Linux и Python 3.11 или новее. Все воркеры DeepSeek по-прежнему запускаются в обязательной песочнице Linux.
