# DeepSeek Team 0.8.4

Релиз объединяет проверенные исправления, оставшиеся в локальных рабочих копиях,
и сохраняет контроль нативного делегирования из 0.8.3.

- Хуки учитывают все незавершённые задачи сессии. Обновление старой завершённой
  записи не скрывает работу, а новая задача координатора или нативного агента
  не обходит более раннее назначение DeepSeek.
- Проверка разрешённых путей, пересечений и актуальности результатов использует
  общие правила. Маска файлов не разрешает удалять содержащий их каталог.
- Проверочные команды поддерживают префиксы вроде
  `PYTHONPATH=src python3 -m unittest`. Разбор команды не исполняет её на хосте;
  проверка зависимостей-путей работает в POSIX shell.
- Импорт выбранных файлов не проходит через символьные ссылки, отклоняет
  связанные файлы назначения и выполняет атомарную замену через открытые каталоги.
  При ошибке последующего файла уже импортированные файлы остаются отмечены
  как подготовленные координатором.
- Изменение настроек проекта проверяет управляемые блоки инструкций до сохранения
  политики, откатывает предыдущие записи при обычных ошибках и сохраняет
  пользовательский текст. Неверный явный `config show --path` больше не подменяется
  текущим каталогом.
- Запуск воркера из Python virtualenv использует разрешённый путь к интерпретатору.
  Его доступность в настоящей песочнице проверяется до чтения ключа провайдера.

Репозитории воркеров остаются отдельными копиями в приватном каталоге состояния.
Внутренние ветки `deepseek/<id>` не появляются среди веток или worktree исходного
проекта. Инструкции координатора рекомендуют существующую изоляцию либо detached
worktree и проверку перед удалением собственных временных веток после интеграции.
Это правило работы координатора, а не служба автоматического удаления.
Неудачные, непринятые и чужие результаты сохраняются.

После обновления обновите инструкции подключённого проекта командой
`deepseek-team init --coordinator codex .` (либо `claude` / `both`). Песочница ОС,
учётные данные и сохранённые права доступа остаются прежними.
