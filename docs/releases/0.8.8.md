# DeepSeek Team 0.8.8

**English** | [Русский](#русский)

This release adds an optional compact **linked** bootstrap for an attached project. It
is opt-in per runtime; the default full mode is unchanged, no hook definition changed,
and no delegation, access, quality or lessons feature changed.

- A runtime opts in by placing the standalone marker
  `<!-- codex-deepseek-team:guidance:linked -->` on its own line **inside** its existing
  managed block, using the same comment prefix as that block's `managed-block:start`
  marker. Place it after the existing `original:...` metadata line; keep the first two
  block lines unchanged. A marker anywhere outside the owned block - in your own text or a fenced
  example - has no effect.
- Before the marker takes effect, the repository must already contain a nonempty, regular,
  UTF-8 `docs/agents/delegation.md` at its root that holds the actual required delegation
  protocol, kept under version control. The package validates that guide but never
  generates, overwrites or updates its content, so the guide stays a human-maintained
  responsibility across later upgrades. Activating the mode with a missing, empty,
  non-UTF-8, symlinked or escaping guide fails and leaves the owned files unchanged.
- In linked mode the package regenerates a compact (under 4 KB) block that mandates
  reading the human-maintained guide and points at the live `deepseek-team status` and
  `config show --effective --instructions --runtime codex|claude` commands instead of
  embedding an effective-profile snapshot. Commands are rendered for the runtime that
  owns the block: a Codex block shows `--runtime codex` and a Claude block shows
  `--runtime claude`.
- The marker survives `init`, explicit config refresh and automatic session/lifecycle
  refresh, so the selected mode persists until the marker is deleted, and `detach` works
  in both modes. Run `init` to intentionally regenerate that project's block. Existing
  full mode remains the default for every unmarked project.
- Permissions, the `off` switch, the worker OS sandbox and the existing hook definitions
  are unchanged. This release changes no hook definition and cannot grant native hook
  trust, so review `/hooks` in the runtime as before.

Upgrade the package, then run `setup` once for each coordinator runtime you installed:

```bash
pipx upgrade deepseek-team
deepseek-team setup --runtime codex --no-key   # or claude / both
```

## Русский

Этот релиз добавляет необязательный компактный **linked**-бутстрап для подключённого
проекта. Он включается отдельно для каждого координатора; обычный полный режим не
меняется, определения хуков не меняются, а функции делегирования, доступа, качества и
уроков не затрагиваются.

- Чтобы включить режим для выбранного координатора, разместите маркер
  `<!-- codex-deepseek-team:guidance:linked -->` на отдельной строке **внутри**
  существующего управляемого блока, с тем же префиксом комментария, что и у маркера
  `managed-block:start` этого блока. Разместите его после существующего служебного
  комментария `original:...`; первые две строки блока оставьте без изменений.
  Маркер вне управляемого блока — в вашем тексте или
  в примере кода — не действует.
- Прежде чем маркер начнёт действовать, в корне репозитория уже должен быть непустой
  обычный файл `docs/agents/delegation.md` в кодировке UTF-8, содержащий собственно
  требуемый протокол делегирования и хранимый под контролем версий. Пакет проверяет этот
  гид, но никогда не создаёт, не перезаписывает и не обновляет его содержимое, поэтому
  гид остаётся обязанностью человека и при последующих обновлениях. Если гид отсутствует,
  пуст, не в UTF-8, является символической ссылкой или выходит за пределы репозитория,
  включение режима завершается ошибкой, а управляемые файлы не меняются.
- В режиме linked пакет создаёт компактный (менее 4 КБ) блок, который обязывает прочитать
  поддерживаемый вручную гид и указывает на актуальные команды `deepseek-team status` и
  `config show --effective --instructions --runtime codex|claude` вместо встраивания снимка
  действующего профиля. Команды формируются для того координатора, которому принадлежит
  блок: блок Codex показывает `--runtime codex`, а блок Claude — `--runtime claude`.
- Маркер переживает `init`, явное обновление конфигурации и автоматическое обновление
  сессии/жизненного цикла, поэтому выбранный режим сохраняется, пока маркер не удалён, а
  `detach` работает в обоих режимах. Запустите `init`, чтобы намеренно пересобрать блок
  этого проекта. Обычный полный режим остаётся значением по умолчанию для любого проекта
  без маркера.
- Права доступа, переключатель `off`, песочница ОС для воркеров и существующие определения
  хуков не меняются. Релиз не меняет определения хуков и не может выдать доверие к нативным
  хукам, поэтому проверяйте `/hooks` в координаторе как раньше.

Обновите пакет и выполните `setup` один раз для каждого установленного координатора:

```bash
pipx upgrade deepseek-team
deepseek-team setup --runtime codex --no-key   # либо claude / both
```
