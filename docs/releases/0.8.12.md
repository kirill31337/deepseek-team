# DeepSeek Team 0.8.12

## English

0.8.12 adds explicit attached-root selection, an orderly task completion command,
and clearer setup and Auto-cost guidance. It keeps the 0.8.11 private worker
storage behavior, its documentation and every historical release note unchanged.

- Launching Codex or Claude Code from a common parent directory can select one
  explicitly attached repository with
  `DEEPSEEK_TEAM_PROJECT_ROOT=/absolute/repo/root`. The variable selects the
  DeepSeek hook context only; it does not make Codex or Claude Code discover child
  or native instructions automatically. Keep using the real project directory for
  tool and worker commands, and pass `--path` to coordination commands.
- An attached, enabled target without a bound selection keeps showing selection
  guidance. A workdir in a different repository cannot inherit another plan, and
  an ambiguous working-directory change stays unscoped. Nothing here widens
  attachment, access or the mandatory OS sandbox.
- `deepseek-team coordination complete --path REPO --task TASK_ID` closes a task
  once every worker result has a disposition and every coordinator or native-agent
  outcome is a current `accepted` or `cancelled`. It reuses the same validation on
  demand, independently of the Stop hook, which still completes a delivered task
  automatically.
- Setup refreshes only managed blocks that already exist in the nearest ancestor
  Git repository. Unrelated ancestor Git metadata without an owned block is
  ignored, while real corrupt-control errors in an owned block are still reported.
- Auto never measures end-to-end cost by itself. The optional operator `--cost-usd`
  records the measured FULL total of a worker, coordinator review and any rework,
  and is absent by default. Unknown stays unknown: there is no quality, speed, cost
  or savings guarantee, and elapsed metadata is not a latency routing objective.
  No percentages or prices are invented.

Upgrade from this GitHub release (the automatic PyPI workflow is disabled; the
coordinator can publish the same verified artifacts manually):

```bash
pipx install --force https://github.com/kirill31337/deepseek-team/releases/download/v0.8.12/deepseek_team-0.8.12-py3-none-any.whl
deepseek-team setup --runtime codex --no-key   # or claude / both
deepseek-team doctor --runtime codex --offline
```

Package installation itself does not run project setup, attach a project or grant
native hook trust.

## Русский

В 0.8.12 добавлены явный выбор подключённого корня, команда упорядоченного
завершения задачи и более понятные пояснения по setup и стоимости в Auto.
Поведение приватного хранилища воркеров из 0.8.11, его документация и все
исторические заметки о версиях сохранены без изменений.

- Запуск Codex или Claude Code из общего родительского каталога позволяет явно
  выбрать один подключённый репозиторий:
  `DEEPSEEK_TEAM_PROJECT_ROOT=/absolute/repo/root`. Переменная выбирает только
  контекст хуков DeepSeek Team; она не заставляет Codex или Claude Code
  автоматически находить инструкции дочерних или нативных проектов. Для команд
  инструментов и воркеров используйте фактический каталог проекта, а командам
  координации передавайте `--path`.
- Подключённая включённая цель без привязанного выбора по-прежнему показывает
  подсказку о выборе. Рабочий каталог в другом репозитории не может
  использовать чужой план, а неоднозначная смена каталога остаётся без области.
  Здесь ничего не расширяет подключение, доступ и обязательную песочницу ОС.
- `deepseek-team coordination complete --path REPO --task TASK_ID` закрывает
  задачу, когда у каждого результата воркера есть решение, а у каждого
  результата координатора или нативного агента — актуальный `accepted` или
  `cancelled`. Команда повторно использует ту же проверку по запросу, независимо
  от хука Stop, который по-прежнему завершает отданную задачу автоматически.
- Setup обновляет только существующие управляемые блоки в ближайшем
  родительском репозитории Git. Посторонние служебные данные Git без
  принадлежащего блока игнорируются, а настоящие ошибки управления в
  принадлежащем блоке по-прежнему сообщаются.
- Auto сам не измеряет сквозную стоимость. Необязательный операторский
  `--cost-usd` записывает полную измеренную сумму: воркер, ревью координатора и
  все доработки; по умолчанию значение отсутствует. Неизвестное остаётся
  неизвестным: гарантий качества, скорости, стоимости или экономии нет, а
  метаданные о длительности не являются целью маршрутизации по задержке.
  Проценты и цены не выдумываются.

Команды обновления и проверки приведены выше. Установка пакета сама не запускает
setup проекта, не подключает проект и не выдаёт доверие хукам координатора.
