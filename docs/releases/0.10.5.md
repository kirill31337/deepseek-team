# DeepSeek Team 0.10.5

## English

0.10.5 is a bugfix release that unblocks affected level-75 full-access
coordination tasks and improves coordination command discovery.

- A cancelled historical coordinator implementation deliverable no longer
  blocks level-75 full-access plan validation or completion. Retention
  validation had been applied to already cancelled work even though started
  scopes cannot be changed or deleted. The exemption requires a current
  cancellation recorded with evidence. Accepted work and stale cancellations
  remain subject to retention checks; worker-assignment requirements are
  preserved. No manual state rewrite or disabling delegation is required.
- Coordination command help now makes available subcommands easier to discover,
  and invalid task-ID errors provide actionable CLI guidance instead of only
  rejecting the value.

Upgrade through the same installer, then refresh setup if appropriate:

```bash
pipx upgrade deepseek-team
deepseek-team setup --runtime codex --no-key   # or claude / both
```

To finish an existing task, use its actual existing task ID. Do not invent a
new ID; session and turn lifecycle hooks create tasks. Copy `TASK_ID` from the
hook context and inspect that task first:

```bash
deepseek-team coordination status --path PROJECT --task TASK_ID --json
```

Once all existing outcomes are terminal, complete the task:

```bash
deepseek-team coordination complete --path PROJECT --task TASK_ID
```

Other legitimate outstanding issues still need to be resolved.

## Русский

0.10.5 — выпуск с исправлениями, который разблокирует затронутые задачи
координации уровня 75 с полным доступом и улучшает обнаружение команд
координации.

- Отменённый исторический пункт реализации координатора больше не блокирует
  проверку или завершение плана уровня 75 с полным доступом. Проверка
  сохранения применялась к уже отменённой работе, хотя начатые области нельзя
  изменить или удалить. Исключение действует только для актуальной отмены с
  записанным обоснованием. Принятая работа и устаревшая отмена по-прежнему
  проходят проверку требований делегирования; требования к назначению воркеров
  сохраняются. Ручное переписывание состояния или отключение делегирования не
  требуется.
- Справка команд координации теперь помогает легче обнаружить доступные
  подкоманды, а ошибки неверного ID задачи содержат действенные подсказки CLI,
  а не только отказ в значении.

Обновление выполняется тем же установщиком; при необходимости обновите setup:

```bash
pipx upgrade deepseek-team
deepseek-team setup --runtime codex --no-key   # или claude / both
```

Чтобы завершить существующую задачу, используйте её фактический ID. Не
создавайте новый ID вручную: задачи создаются хуками жизненного цикла сессии и
хода. Скопируйте `TASK_ID` из контекста хука и сначала проверьте эту задачу:

```bash
deepseek-team coordination status --path PROJECT --task TASK_ID --json
```

Когда все существующие результаты станут терминальными, завершите задачу:

```bash
deepseek-team coordination complete --path PROJECT --task TASK_ID
```

Прочие реальные незавершённые проблемы по-прежнему нужно устранить.
